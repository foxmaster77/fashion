# ORI — fashion storefront

Premium editorial clothing e-commerce site. Single-file HTML storefront with Three.js cloth hero, scroll-driven sections, product page, cart drawer, demo checkout, and a closing interactive 3D paper certificate.

## Run

Serve the folder over HTTP (needed for paper3d.js):

```
python -m http.server 8080
```

Then open http://localhost:8080/ORI%20Store.html
